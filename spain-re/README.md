## Контекст проекта

- Основательница — 23 года в Испании, бэкграунд в медицинском туризме; технический партнёр — эксперт в IT/AI (дигитализация — сквозная тема всех стратегий).
- `claude-brainstorm/` и `gpt/` — две независимые синтетические симуляции одного вопроса; их выводы сходятся в ключевых точках (платный deal memo, supply-first, комплаенс, «AI внутри, не на витрине») — см. сравнение в истории проекта.
- Все симуляции — не полевое исследование; ключевые выводы требуют проверки на реальном рынке (планы валидации есть в обоих отчётах).
