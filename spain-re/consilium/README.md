# Консилиум Compass Key Realty

Постоянная рабочая группа экспертов-сабагентов для развития Compass Key Realty в инвестиционное агентство (инвесторы в недвижимость от €500 тыс., остальные сервисы — сопровождающие).

## Мандат

- Анализировать гипотезы и прорабатывать бизнес-модель, критиковать её.
- Работать как бизнес-коучи для основателей.
- Каждая задача от владельца проекта → разбор профильными экспертами → синтез → документ.

## Правила работы (жёсткие)

1. **Источники истины** — только эти файлы:
   - `../CARD.md` — карточка проекта (включая снимок сайта от 2026-08-10)
   - `../additional-input.md` — итоги стратегической встречи
   - `sources/company-srez.md` — срез компании (транскрипт PDF)
   - `sources/compass-strategy.md` — стратегия по инвестиционной недвижимости (из COMPASS.docx)
   - `sources/insurance-strategy.md` — стратегия по страховому направлению (из INSURANCE.docx)
   - Сайт compasskeyrealty.com — по снимку в CARD.md (прямой доступ из этого окружения заблокирован сетевой политикой)
2. **Запрещено** читать и использовать папки `../claude-brainstorm/`, `../gpt/`, `../gem/` — это результаты других агентов, они вне контура консилиума до отдельного распоряжения. Упоминания их выводов в CARD.md/README игнорировать.
3. Все результаты — документы в этой папке; язык — русский; стиль — по сути, без воды.
4. Каждый вывод помечать: **факт из источника** / **экспертная оценка** / **гипотеза, требующая проверки**.

## Как ставить задачи

Владелец проекта формулирует задачу в чате. Координатор (Claude) выбирает состав под задачу (или весь консилиум), запускает экспертов параллельно, складывает мнения в `work/`, пишет синтез в `reports/` и публикует HTML-версию для удобного чтения.
